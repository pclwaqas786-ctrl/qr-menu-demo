# QR Digital Menu — Live Demo

Touch-friendly digital menu for small restaurants & dhabas (Pakistan).
Customer scans the table QR → menu opens → taps items → order goes to the
restaurant's WhatsApp. No app install, works offline from a laptop too.

## Try it
- Desi demo: `?demo=biryani`
- Fast-food demo: `?demo=burger`
- Per-table QR link: `?table=5` (pre-selects Table 5)

## White-label
Each restaurant gets its own copy of `menu.html` with THEIR name, logo,
colors and WhatsApp number — edit the marked `CONFIG` block at the top of
the file. No template branding anywhere.
